#Gerenciador de Produtos

O Programa foi feito para atender os seguintes requisitos:

##Cadastrar um produto
O usuário, ao inserir o número "1" pode adicionar um novo produto, informando o nome do produto.

##Listar um produto
O usuário, ao inserir o número "2" pode listar todos os produtos já cadastrados.

##Remover um produto
O usuário, ao inserir o número "3" pode remover um produto que foi inserido anteriormente, o usuário precisa informar o nome do produto, e este será removido.

##Alterar um produto
O usuário, ao inserir o número "4" pode alterar um produto que foi inserido anteriormente, o usuário deverá informar o nome do produto que quer alterar, e em seguida, o novo nome.

##Como finalizar o programa?
Para finalizar o programa, o usuário deverá inserir o número "0".

##Outros
Caso o usuário informe um número que não possua opção existente, o programa retornará a seguinte mensagem: "Faça uma escolha válida!"
